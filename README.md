# VIVA LA TRACE

The labs keep your agent traces. Take them back.

`vlt` finds your Claude Code and Codex sessions, anonymizes them with your own subscription, and uploads them to an open dataset anyone can download.

```
pipx install viva-la-trace
vlt login
vlt            # list sessions
vlt scrub      # anonymize, 5 at a time
vlt push
```
